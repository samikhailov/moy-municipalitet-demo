# Мой Муниципалитет — трекер поручений (демо)

Демонстрационная версия трекера поручений для 23 муниципалитетов Чувашской Республики.
Работает целиком в браузере, без сервера: данные хранятся в `localStorage`.

## Запуск

```bash
npm install
npm run dev       # режим разработки, http://localhost:5173
npm run build     # сборка в папку dist/
npm run preview   # просмотр собранной версии
```

Собранную папку `dist/` можно открыть с любого статического хостинга (GitHub Pages, S3, nginx):
используются относительные пути и hash-маршрутизация.

## Демонстрационные логины

Пароль не проверяется, роль определяется по логину.

| Логин     | Роль                 | Пользователь               | Муниципалитет  |
|-----------|----------------------|----------------------------|----------------|
| `curator` | Куратор              | Смирнова Елена Викторовна  | все            |
| `glava`   | Глава муниципалитета | Николаев Сергей Петрович   | Моргаушский МО |
| `manager` | Управляющий делами   | Ильина Ольга Андреевна     | Моргаушский МО |

## Сценарий демо

1. **Куратор** создаёт поручение для Моргаушского МО. Статус поручения: «На распределение».
2. **Глава** открывает поручение, назначает исполнителя и нажимает «Передать в работу». Статус меняется на «В работе».
3. **Управляющий делами** открывает поручение и нажимает «Отметить исполненным». Статус меняется на «Исполнено».

Кнопка «Сбросить демоданные» в боковом меню возвращает исходный набор поручений.

## Где что менять

| Что                                    | Файл                          |
|----------------------------------------|-------------------------------|
| Пользователи, логины, исполнители      | `src/config/users.ts`         |
| Список муниципалитетов и статусов      | `src/lib/municipalities.ts`   |
| Демоданные (генерируются детерминированно, сроки отсчитываются от текущей даты) | `src/data/seed.ts` |
| Хранилище и права доступа по ролям     | `src/store/store.tsx`         |
| Экраны                                 | `src/pages/`                  |
| Компоненты дизайн-системы (shadcn/ui)  | `src/components/ui`, `src/components/blocks` |
| Цвета и токены                         | `src/index.css`               |

Если поменялась структура данных, увеличьте `DATA_VERSION` в `src/store/store.tsx`. Тогда у всех пользователей сохранённые данные заменятся новыми демоданными.

## Ограничения демо

- Вложения не загружаются: сохраняется только имя файла.
- Нет экрана списка поручений и редактирования поручения куратором. Эти экраны не входят в демо.
- Права доступа проверяются только на клиенте.

## Стек

React 18, TypeScript, Vite, Tailwind CSS v4, shadcn/ui (Radix UI), react-day-picker, lucide-react.
